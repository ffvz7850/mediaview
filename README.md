# 极速媒体浏览 (mediaview)

替代飞牛 fnOS 网页版的图片与视频极速浏览应用，核心目标是极致加载速度，解决网页版浏览媒体时加载慢、卡顿的问题。

## 特性

- **秒开图片与视频**：基于 ffmpeg 硬件解码 + libjpeg-turbo 优化，急速打开
- **虚拟滚动**：列表滚动流畅不卡顿，支持万张图片目录
- **左右滑动切换**：大图浏览支持左右滑动/点击切换，预加载后续图片
- **缩略图管理**：可开关缩略图生成、自定义缩略图存放位置、自定义尺寸与画质
- **接管系统缩略图**：可替代飞牛系统的 auto_thumbnailer，文件管理器显示本应用生成的缩略图
- **硬件解码**：视频缩略图抽帧走 VAAPI 核显硬解（AMD/Intel/NVIDIA 均支持），失败自动回退软件解码
- **CPU 限制**：可限制缩略图生成使用的 CPU 核心数，避免占满系统资源
- **明暗主题**：支持明亮/暗色主题切换
- **翻页动画**：滑动/淡入淡出/缩放/无动画 四种可选
- **双架构**：支持 x86_64 和 arm64

## 系统要求

- 飞牛 fnOS ≥ 1.2.0401
- x86_64 或 arm64 架构

## 安装

1. 下载对应架构的 FPK 安装包：
   - `mediaview_<version>_x86.fpk` — x86_64 架构
   - `mediaview_<version>_arm.fpk` — arm64 架构
2. 在飞牛桌面打开「应用商店」→ 右上角「手动安装」
3. 选择下载的 FPK 文件，等待安装完成
4. 安装后在桌面找到「极速媒体浏览」图标打开

## 设为默认打开方式

安装后，在文件管理器中右键图片或视频文件 →「打开方式」→ 选择「极速媒体浏览」→ 勾选「始终使用此应用打开」。

## 设置说明

打开应用后点击右上角 ⚙ 进入设置：

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 生成缩略图 | 关闭后列表改用文件图标，不再占用磁盘与 CPU | 开启 |
| 界面主题 | 明亮/暗色 | 明亮 |
| 接管系统缩略图 | 停止飞牛系统缩略图服务，统一由本应用生成（需重启应用生效） | 关闭 |
| CPU 核心数 | 限制缩略图生成使用的核心数，0=不限制 | 0 |
| 缩略图生成并发 | 同时解码的图片数量 | 6 |
| 后台预加载并发 | 进入目录后后台预生成缩略图的 worker 数 | 3 |
| 视频硬件解码 | 视频缩略图走 VAAPI 硬解 | 开启 |
| 图片硬件解码（实验性） | JPEG 缩略图走 VAAPI 硬解（部分 AMD 核显可能产出绿图，建议关闭） | 关闭 |
| 大图预加载数量 | 切换图片后预加载后续 N 张 | 2 |
| 翻页动画 | 滑动/淡入淡出/缩放/无动画 | 滑动 |
| 大图浏览方式 | 独立窗口/窗口内遮罩 | 独立窗口 |
| 缩略图存放位置 | 自定义缩略图缓存目录 | 默认运行期目录 |
| 缩略图尺寸 | 160/240/320/480/640 px | 320 |
| 画质 | 60~95 | 80 |

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 上一张/下一张 | ← / → 或 鼠标滚轮 |
| 放大/缩小 | 滚轮（大图浏览时） |
| 适应窗口 | 双击 |
| 全屏 | 右下角全屏按钮 |
| 关闭大图 | Esc 或 左上角序号 |

## 缩略图缓存位置

- 默认：应用运行期目录下的 `thumb/` 文件夹
- 自定义：在设置中指定，按 `{size}/{原文件相对路径}` 结构存放
- 系统缩略图接管模式下：文件管理器的 list=320px / medium=800px / big=1920px 三种尺寸均由本应用生成

## 卸载

在飞牛应用管理中卸载即可。卸载时可选择是否清除缩略图缓存和软件数据。

如果开启了「接管系统缩略图」，卸载后会自动恢复飞牛系统的 auto_thumbnailer 服务。

## 架构说明

- **后端**：Go 语言，micro_app 网关模式，通过 unix socket 与飞牛桌面通信
- **前端**：原生 HTML/CSS/JS，无构建依赖，通过 go:embed 嵌入二进制
- **缩略图引擎**：ffmpeg（VAAPI 硬解 + 软件解码回退）+ Go 原生 image/jpeg/png/gif 解码
- **视频播放**：浏览器原生 video 标签 + ffmpeg 转码
- **系统缩略图接管**：监听 `/var/run/auto_thumbnailer.socket`，实现飞牛缩略图 API

## 编译

```bash
# x86_64
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o mediaview .

# arm64
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o mediaview .
```

打包 FPK 需要飞牛官方的 fnpack 工具。
